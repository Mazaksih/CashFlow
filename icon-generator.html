💸 PWA Icon Generator

Klik "Generate & Download Semua Icon" untuk membuat semua ukuran icon yang dibutuhkan PWA secara otomatis.

✅ Semua icon berhasil di-download!
Cara pakai setelah download:
1. Buat folder bernama icons di repository GitHub Anda
2. Upload semua file icon-*.png yang di-download ke folder icons/
3. Struktur folder Anda akan menjadi:
cashflow-app/
  ├── index.html
  ├── manifest.json
  ├── sw.js
  └── icons/
      ├── icon-192.png
      └── icon-512.png (dan lainnya)
