🔗 Google Apps Script URL

URL ini didapat setelah Anda deploy Apps Script sebagai Web App. Setiap deploy versi baru, update di sini.

Belum diatur
Contoh: https://script.google.com/macros/s/AKfyc.../exec
ℹ️ Cara Mendapatkan URL Baru
1. Buka spreadsheet → Extensions → Apps Script
2. Klik Deploy → Manage deployments
3. Klik ✏️ edit → pilih New version → Deploy
4. Copy URL → paste di kolom Update URL di atas → Simpan
